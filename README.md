# Arogya — Healthcare for Every Village

A healthcare platform that bridges rural communities and quality medical care through **ASHA workers**, **doctors**, and **patients**. Built for Hackstomp 2026.

## Features

- **ASHA workers:** Register patients, capture symptoms, upload photos/reports, sync cases to doctors, request video calls, view patient history, download prescriptions as PDF.
- **Doctors:** Dashboard with urgent / attention / routine cases, accept or reject video calls, join consultations via Sarvam TeleHealth (speech-to-text), view patients by date, analytics (triage, disease-by-area).
- **Patients / users:** Register and login with Aadhaar + password, book doctor/video call, view past records, medicine reminders, download health history as PDF.
- **Multilingual:** English, Hindi, Marathi, Gujarati, Tamil, Telugu, Kannada, Bengali.
- **AI triage:** RED / YELLOW / GREEN severity; offline-first sync when connectivity returns.
